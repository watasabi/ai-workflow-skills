Why skills need a package manager

A "skill" — a folder with a SKILL.md describing when and how an agent should act — is a great way to give coding agents durable, reviewable knowledge. Once you have more than a couple, you need to version, share, and install them consistently. That's what this tool does.

📦

Versioned catalog

Skills live as plain folders in a local directory or Git repo — easy to diff, review, and fork.

🔌

Multi-agent

Installs into the right folder for 19+ agents, with auto-detection from your project's config folders.

🔒

Tracked installs

Every install is recorded with content hashes in a project-local lockfile, so updates only touch what changed.

🖥️

Interactive TUI

Browse, install, update, and remove skills without memorizing flags.

🧾

Auditable

Every install, update, and removal is appended to a local audit log.

🧩

Bring your own

Compatible with the agent-skills convention — any existing SKILL.md folder works as-is.

Quickstart

Install the CLI, point it at a catalog, and install a skill into your project.

git clone https://github.com/watasabi/ai-workflow-skills.git
cd ai-workflow-skills
cargo install --path . --locked

export AI_WORKFLOW_SKILLS_CATALOG="$(pwd)/catalog"

ai-workflow-skills list
ai-workflow-skills install -s tool-github-cli -a cursor -a claude-code
